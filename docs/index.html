What's in the box

A terminal agent that doesn't cut corners.

Everything you'd want from a serious agent client — and a few things you didn't know you wanted — without leaving the terminal.

⌘

Multi-provider TUI

One wizard, seven providers: local llama.cpp on your GPU, a remote llama-server, or OpenAI, Anthropic, xAI, OpenRouter, nano-gpt. Back-navigation, last-used highlighting, per-provider favorites.

▟

Live GPU telemetry

In local mode: a real-time GPU-util sparkline, VRAM / CPU / RAM bars, temperature, power and tok/s — straight from nvidia-smi and psutil.

⏺

Clean widget chat

Claude-Code-style: a gray user bubble, inline collapsible thinking, compact colored tool bullets with inline diffs, and an animated working bar while the model runs.

⚿

Permission gating

Allow / always / deny prompts for any flagged operation — writes, exec, secrets. Opt out per-run with --dangerously-skip-permissions.

✦

Atlassian, built in

Search, read and — behind a prompt — write Jira issues and Confluence pages (incl. search by author and paginated reads), all sharing one Atlassian token.

⬡

MCP tool server

Serve the whole toolset over MCP with a web backoffice to enable/disable tools and author custom shell tools — no redeploy of the agent.

The tool layer

Portable, stdlib-only, shared everywhere.

The same tools back the TUI, the headless agent and the MCP server. Reads are free; writes and execution go through the permission prompt.

MCP server + backoffice

Manage your tools live.

  • ▸Expose the whole toolset over the Model Context Protocol (streamable-HTTP).
  • ▸Enable or disable any tool and see the exact description the model receives.
  • ▸Author custom shell tools — name + description + a command with {args} — saved and hot-restarted, no agent redeploy.
  • ▸Point the TUI at it; remote tools are auto-discovered with a mac_ prefix.

bench/

A benchmark that actually decides.

A decisive, reproducible tool-calling benchmark for local GGUF models: deterministic decoding, programmatic graders (no vibes), resumable runs, and a weighted leaderboard that tells you which model to burn your VRAM on.

Overall leaderboard — basic tier (read-only tool tasks)

Ornith-1.0-9B (Q4_K_M) is the overall #1.

A 9B model that tops the basic tier (96.9), stays top-tier on advanced (97.5), and runs away with hardcore — 94.3, the best score the benchmark has ever recorded — all while being fast and token-efficient. Uniquely, thinking doesn't hurt it.

The key finding: enabling a model's own "thinking" is neutral-to-helpful for a few, but hurts most others — sometimes by 20–30 points.

Get started

Two ways in.

Grab a standalone bundle — no Python needed — or install from source with pipx. First launch with no config drops you straight into the setup wizard.

no python Download a release

Bundles for Windows, macOS and Linux are attached to every release.

unpack & runcopy
# Windows: unzip raiko-windows.zip, then
raiko\raiko.exe

# macOS / Linux:
tar -xzf raiko-linux.tar.gz && ./raiko

devs Install with Python

A console script named raiko lands on your PATH.

pipxcopy
pipx install git+https://github.com/ajaniramon/raiko-toolkit
# then: raiko

# or, in a clone:
pip install -e .   →  raiko
