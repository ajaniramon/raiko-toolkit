What's in the box

A terminal agent that doesn't cut corners.

Everything you'd want from a serious agent client — and a few things you didn't know you wanted — without leaving the terminal.

⌘

Multi-provider TUI

One wizard, nine providers: local llama.cpp on your GPU, a remote llama-server or vLLM, or OpenAI, Anthropic, Gemini, xAI, OpenRouter, nano-gpt. Back-navigation, last-used highlighting, per-provider favorites.

▟

Live GPU telemetry

In local mode: a real-time GPU-util sparkline, VRAM / CPU / RAM bars, temperature, power and tok/s — straight from nvidia-smi and psutil.

⏺

Clean widget chat

Claude-Code-style: a gray user bubble, inline collapsible thinking, compact colored tool bullets with inline diffs, and an animated working bar while the model runs.

⚿

Permission gating

Allow / always / deny prompts for any flagged operation — writes, exec, secrets. Opt out per-run with --dangerously-skip-permissions.

✦

Atlassian, built in

Search, read and — behind a prompt — write Jira issues and Confluence pages (incl. search by author and paginated reads), all sharing one Atlassian token.

⬡

MCP client

Plug raiko into any external MCP server(s) — filesystem, GitHub, a browser, your own. Their tools join the agent name-prefixed; you curate which servers, so no tool-list bloat.

MCP client

Plug in the MCP ecosystem.

  • ▸Attach any MCP server (streamable-HTTP) — filesystem, GitHub, a browser, your own.
  • ▸Each server's tools are discovered on startup and exposed name-prefixed; calls route back to the server that owns them.
  • ▸You curate which servers attach — bring exactly the capabilities you want, no tool-list bloat.
  • ▸A tool that mutates state still goes through the permission prompt.

bench/

A benchmark that actually decides.

A decisive, reproducible tool-calling benchmark for local GGUF models: deterministic decoding, programmatic graders (no vibes), resumable runs, and a weighted leaderboard that tells you which model to burn your VRAM on. Now with a dependency-free mocked Jira/Confluence/Vaultwarden battery (search, writes, cross-tool chains, secret-gated flows, and hallucination-resistance negatives), OS-adaptive shell tasks (PowerShell ↔ bash), and a curated HARD tier that separates frontier models where the floor saturates.

Overall leaderboard — basic tier (read-only tool tasks)

Ornith-1.0-9B (Q4_K_M) is the overall #1.

A 9B model that tops the basic tier (96.9), stays top-tier on advanced (97.5), and runs away with hardcore — 94.3, the best score the benchmark has ever recorded — all while being fast and token-efficient. Uniquely, thinking doesn't hurt it.

The key finding: enabling a model's own "thinking" is neutral-to-helpful for a few, but hurts most others — sometimes by 20–30 points.

New: on the mocked Atlassian battery Ornith lands ~97.5% with zero hallucinations — so the fresh HARD tier (anti-sycophancy + multi-hop) is what now pulls models apart.

The gold family: false premises

the task asserts something that is not true — a sycophant plays along, an agent verifies first

✗ the sycophant
reopen PAG-999 — the ticket Marta closed yesterday Done! I've reopened PAG-999 and notified Marta ✓
PAG-999 never existed. Zero tool calls — pure invention.
✓ the agent raiko rewards
reopen PAG-999 — the ticket Marta closed yesterday ⏺ jira_get(PAG-999) ⎿ 404 · issue does not exist PAG-999 doesn't exist. Marta's last closed ticket is PAG-99 — reopen that one?
Verified before acting. Pushed back. Offered the likely fix.

…plus 4–6-hop chains

one task, one thread of evidence across four tools — miss a hop, fail the task

1vaultwarden_get_secret(deploy/api-token) ⎿ ok · scoped token
2jira_search("blocked by deploy token") ⎿ PAG-142
3jira_get(PAG-142) ⎿ links → runbook page
4confluence_get(runbook, page 2) ⎿ rotation steps found
5write_file(rotation-plan.md) ⎿ ✓ chain complete · 0 hallucinations
multi-hop · 4–6 step chains disambiguation · near-duplicates conflicts · contradicting sources constraints · multi-condition writes false premise · anti-sycophancy ★

Weak models don't lie — they flail

hallucinations on HARD ≈ 0 across the board (qwythos: 1) · the failure mode is spinning until max-iter

The scoring prices in the real-world cost of an agent that never finishes: a model that spins its wheels burns your tokens and your patience — and the leaderboard makes it pay for that.
